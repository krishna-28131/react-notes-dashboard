# React Notes Dashboard

A modern, responsive notes dashboard built with React and Vite. It allows users to add, view, and organize notes locally. Note data is persisted securely using `localStorage`.

## Links
- **GitHub Repository**: [https://github.com/krishna-28131/react-notes-dashboard](https://github.com/krishna-28131/react-notes-dashboard)

## Features
- Add, edit, and delete notes.
- Data persistence via localStorage.
- Auto-focus input fields for quick note-taking.
- Built using React Context API for state management.
- Fast local development with Vite.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
